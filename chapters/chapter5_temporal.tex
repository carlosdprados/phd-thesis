\section{Introduction and Scope}\label{sec:ch5_intro}
%% ------------------------------------------------------------

\Cref{ch:poc,ch:comparative} established and quantified the slow, volatile response of these polymer-electrolyte composites. Behavioural models fitted to that response are now evaluated on temporal-computing tasks. A reservoir maps a time-varying input onto a high-dimensional dynamical state from which a linear read-out can recover temporal information.

The central comparison is between a bank drawn from one composition and a bank spanning several measured timescales. The latter should help when a target depends on several lags, but need not improve a task dominated by one timescale. Wearable \emph{affective computing} (the recognition of emotional and physiological state) provides a relevant test because its signals contain both fast and slow components. The evaluation proceeds from reservoir benchmarks to physiological streams, \WESAD{} classification, and tests with sensor noise, an independent corpus, and wrist-band data.

All results in this chapter are \emph{in silico}; no new devices were fabricated. Each node is a compact behavioural model parameterised by the fits in \cref{ch:comparative} (\cref{sec:ch5_model}), and every read-out is a single linear ridge regression. Demonstration~A tests whether one composition suffices for a single-timescale feature. Demonstration~B tests whether a composition-diverse bank improves multi-timescale tasks.

\section{Measured Behavioural Model}\label{sec:ch5_model}
%% ------------------------------------------------------------

Each composition cell is reduced to a compact behavioural model and used as one reservoir node. The model is fitted only to the three common measurements of \cref{ch:comparative}: hysteresis, pulsed potentiation, and delayed depotentiation. Its parameters therefore derive from measured device data.

Each replicated composition cell is summarised by a \emph{parameter card}: the model-free half-enhancement time $t_{1/2,c}$, any identified stretch exponent $\beta_c$, the potentiation growth exponent $\alpha_c$, the measured peak ratio $R_{\mathrm{peak},c}$, and the pulse count $N_{\mathrm{peak},c}$ at that peak. The fading memory is the stretched-exponential (Kohlrausch) retention identified in \cref{ch:comparative},
\[
  \lambda_c(\Delta t) \;=\; \exp\!\big[-(\Delta t/\tau_c)^{\beta_c}\big],
\]
where $\tau_c=t_{1/2,c}/(\ln 2)^{1/\beta_c}$ is derived so that every card reproduces the primary, model-free cell-median half-time exactly. For cells without an identified stretch exponent, $\beta_c=1$ and therefore $\tau_c=t_{1/2,c}/\ln 2$. The write envelope is
\[
  \frac{G(N)}{G_0}=1+(R_{\mathrm{peak},c}-1)
  \left(\frac{N}{N_{\mathrm{peak},c}}\right)^{\alpha_c},
  \qquad 0\leq N\leq N_{\mathrm{peak},c}.
\]
It uses the measured baseline, exponent, peak, and pulse count rather than an unbounded power law. Where a measured train turns over after its peak, the node is capped at the peak: the post-peak recovery dynamics were not measured and are not extrapolated.

Driven by a rate-coded input $u_n \in [0,1]$ sampled at interval $\Delta t$, a single device node updates as
\[
  \ell^{(i)}_n=\lambda_i x^{(i)}_{n-1},\qquad
  p^{(i)}_n=\operatorname{clip}\!\left[
    (\ell^{(i)}_n)^{1/\alpha_i}
    +\frac{\operatorname{clip}(w_i u_n,0,1)}{N_{\mathrm{peak},i}},0,1\right],
\]
\[
  x^{(i)}_n=(p^{(i)}_n)^{\alpha_i},\qquad
  \frac{G^{(i)}_n}{G^{(i)}_0}=1+(R_{\mathrm{peak},i}-1)x^{(i)}_n,qquad
  \lambda_i=\exp\!\big[-(\Delta t/\tau_i)^{\beta_i}\big].
\]
Here $x_i\in[0,1]$ is the normalised enhancement, $w_i$ is a non-negative input mask, and one full-scale sample advances the pulse-progress coordinate by at most one effective pulse. That sample-to-pulse mapping is a modelling convention, not a measured circuit timing relation. With no leakage and unit input the recurrence reaches the measured peak after $N_{\mathrm{peak},i}$ updates and cannot exceed it; with no input it follows the measured decay. The internal state is assumed to be read sub-threshold without disturbance, as in the proof-of-concept device of \cref{ch:poc}. Every read-out is a single \emph{linear} ridge regression on the device states.

Write nonlinearity and fading memory were measured at different write amplitudes (\SI{3}{\volt} for potentiation and \SI{4}{\volt} for depotentiation; \cref{tab:ch4_protocols}). Combining them in one node assumes that the two regimes are compatible and probably underestimates the coupling between drive and retention. Both measurements also used a single, effectively common inter-pulse cadence, so the model does not resolve input timing below that cadence. The gold/\TMPE{} negative-polarity corpus of \cref{ch:comparative} measures integration and relaxation within single runs and finds both interval-dependent potentiation and written-depth-dependent relaxation. Because it uses another host, electrode, polarity, and read protocol, it does not provide parameters for the banks used here. The experiment needed for the lead composition is specified in \cref{sec:ch5_limitations}. Per-cell parameter cards and all simulation and read-out settings are tabulated in \siTempRef{app:ch5_settings}.

\section{Reservoir Computing and the Common Metric Language}\label{sec:ch5_framework}
%% ------------------------------------------------------------

\paragraph{The reservoir principle.} Reservoir computing uses a fixed dynamical system whose state is connected to a trained linear read-out \cite{Jaeger2001ESN,Maass2002LSM,LukoseviciusJaeger2009}. A physical reservoir requires fading memory, so its state retains recent input history, and a nonlinear response that maps inputs into features accessible to the read-out. \Cref{ch:comparative} measures both properties in these devices: stretched-exponential depotentiation supplies fading memory, and compressive potentiation supplies nonlinearity. Memristive and organic implementations have previously used the same combination \cite{Tanaka2019,Du2017,Zhong2021,Cucchi2021}. The behavioural models test whether the measured polymer-electrolyte response supplies that combination.

\paragraph{Architecture.} The reservoir is a spatial bank of $N$ \emph{independent} device nodes, each represented by the behavioural model of \cref{sec:ch5_model} and driven by a randomly masked copy of the input. With no inter-node recurrence, differences between banks arise from their intrinsic timescales, device-to-device scatter, and input masks rather than engineered connectivity. For Demonstration~A, the same single-composition node could instead be deployed as a time-multiplexed delay-feedback reservoir with virtual nodes along a delay line \cite{Appeltant2011}; the spatial bank is used throughout for consistency.

\paragraph{Common metrics.} Linear memory capacity $\mathrm{MC}_k$ and its total \cite{Jaeger2002STM} quantify the past input recoverable at each lag. \NARMA{} \cite{AtiyaParlos2000} provides a nonlinear system-identification benchmark, and the information-processing-capacity framework \cite{Dambre2012} separates linear and nonlinear contributions (\cref{fig:ch5_ipc}). Affective tasks are scored by class-balanced macro-F1. Robustness is tested by injecting the measured within-cell timescale spread into the bank (\cref{fig:ch5_robustness}); no common scatter estimate is assumed for $\alpha$ or $\beta$.

\section{Benchmark Tier: Capacity and System Identification}\label{sec:ch5_benchmarks}
%% ------------------------------------------------------------

Reservoir suitability is first evaluated without an application-specific task. Linear memory capacity measures fading memory, while information-processing capacity separates its linear and nonlinear components. The \NARMA{} system-identification task is used only to rank compositions, not to claim absolute performance. All three benchmarks use a random rate-coded input, $N$ device nodes, and a linear ridge read-out.

\paragraph{Statistical units.} Random input and bank seeds sample the algorithm's sensitivity to stochastic initialisation; they are not independent devices, experiments, or subjects. Seed-only benchmark comparisons therefore report means, standard deviations, and sign consistency without inferential $p$-values. Inferential paired tests are reserved for independent held-out subjects in the physiological-corpus analyses, or for independently fabricated devices in the experimental chapters. The complete distinction is recorded in \siTempRef{tab:ch5_settings}.

\paragraph{Memory capacity.} The linear memory capacity of Jaeger measures how much of the past input a reservoir can reconstruct: $\mathrm{MC}_k$ is the squared correlation between a ridge reconstruction of the input $k$ steps ago and its true value, and the total is the sum over all lags, bounded above by the number of nodes $N$ \cite{Jaeger2002STM}. \Cref{fig:ch5_mc_curve} compares two banks of equal size ($N=24$): a \emph{homogeneous} bank of jittered copies of the lead cell (\PEO{}~0.3/0.09) and a \emph{heterogeneous} bank spanning the replicated composition grid ($\tau\approx 4$--$30$\,s). Under the bounded, peak-calibrated update, total capacity changes from $4.19\pm0.42$ to $4.52\pm0.67$ (means $\pm$ SD over ten random input/bank seeds), a ratio of $1.08\pm0.15$ and a paired gain of $0.33\pm0.60$. The heterogeneous value is higher in seven of ten seed pairs, so the linear-memory benchmark does \emph{not} establish a robust heterogeneity advantage. It does show a different lag profile: single-step recall rises from $\mathrm{MC}_1=0.52$ to $0.99$, whereas recall at lag~15 falls from $0.11$ to $0.05$. The composition spread therefore redistributes recoverable information toward short lags in this architecture rather than increasing total linear capacity decisively.

\paragraph{Composition sweep and the single-node optimum.} The same benchmarks, run on single-composition banks, rank the compositions against one another and so test the Demonstration-A claim that one cell suffices for a single-timescale task. \Cref{fig:ch5_composition_sweep} shows that the lead cell \PEO{}~0.3/0.09 attains the highest single-composition memory capacity ($3.76 \pm 0.31$, mean $\pm$ SD over ten seeds), while the neighbouring \PEO{}~0.3/0.045 cell is marginally better on the \NARMA{} system-identification benchmark \cite{AtiyaParlos2000} (NRMSE $0.586 \pm 0.021$ against the lead's $0.594 \pm 0.030$). Both optima fall in the low-\PEO{} row that \cref{ch:comparative} identifies as carrying the longer fading-memory times. This supports the narrower Demonstration-A statement that the lead composition is a reasonable single-timescale operating point; the small differences between the two low-\PEO{} cells are algorithmic rankings, not experimental evidence of a unique optimum. The \NARMA{} numbers carry only \emph{relative} weight: the absolute error is high ($\approx 0.6$--$0.9$) because a bank of independent, non-recurrent nodes is a weak \NARMA{} reservoir.

\paragraph{Comparison with randomly distributed timescales.} A generic echo-state bank of the same size tests whether the measured timescales are individually important or whether their range is sufficient. A random bank spanning approximately the same range ($\tau=3$--$30$\,s) has a memory capacity of $4.97\pm0.78$, compared with $4.52\pm0.67$ for the device bank (ten matched seeds; the device is higher in four). Expanding the random range to $0.5$--$60$\,s raises the capacity to $5.56\pm0.74$ (the device is higher in two). The measured values are therefore not uniquely optimal; this control attributes the available linear memory to the range of fading times rather than to their exact distribution. The broader-range result is only a modelling prompt: the corresponding slow devices have not been measured.

\paragraph{Linear and nonlinear capacity.} Memory capacity counts only linearly recoverable information. The information-processing-capacity framework of Dambre et al.\ decomposes total capacity into orthogonal polynomial degrees: degree-one terms give linear capacity, while degree-two terms measure nonlinear self and cross-lag transformations; the total is bounded by the node count $N$ \cite{Dambre2012}. \Cref{fig:ch5_ipc} reports this decomposition. The homogeneous bank has total capacity $6.31\pm0.44$, comprising $4.47$ linear and $1.84$ nonlinear capacity. The heterogeneous bank reaches $10.33\pm0.87$, comprising $5.46$ linear and $4.88$ nonlinear capacity; its nonlinear increment of $3.04$ is positive in all ten seed pairs. Of the heterogeneous nonlinear capacity, $2.67$ is from self terms and $2.21$ from cross-lag products. This is a stronger algorithmic result than the total linear-memory comparison, but still a sensitivity result for the composed behavioural model rather than an experimental population estimate.

\section{Affective Computing}\label{sec:ch5_affect}
%% ------------------------------------------------------------

Affective computing uses physiological signals to infer emotional and physiological state~\cite{Picard1997}. The device timescales, from a few seconds to tens of seconds, overlap the phasic electrodermal, respiration, and heart-rate-variability bands without time rescaling (\cref{tab:ch5_bands}). These signals also contain several timescales at once: phasic electrodermal responses, respiration and heart-rate-variability rhythms over seconds, and tonic levels drifting over minutes~\cite{Boucsein2012EDA,TaskForce1996HRV,ChourpiliadisBhardwaj2022}. \Cref{fig:ch5_tau_coverage} places the measured relaxation time of each composition on the same axis as these physiological bands and shows the minutes-scale range not reached by composition alone.

\paragraph{Extending the model to tonic timescales.} Raising the write amplitude lengthens fading memory in the measurements of \cref{ch:comparative}. Adding modelled nodes at $\tau=120$ and \SI{300}{\second} raises the random-input long-lag capacity beyond \SI{75}{\second} from $0.20$ to $0.91$ and total capacity from $4.52$ to $5.03$; both changes are positive in all ten seed pairs (\siTempRef{app:ch5_controls}). On the physiological streams, reconstruction at delays up to \SI{120}{\second} is reassessed in \cref{sec:ch5_physio}. This extension is explicitly hypothetical because no minutes-scale cell was measured and the drive-amplitude data do not identify these two time constants. A matched drive-amplitude experiment at these timescales is required to test it.

The experiments that follow use the Wearable Stress and Affect Detection corpus (\WESAD{}) of Schmidt et al.\ \cite{Schmidt2018WESAD}: fifteen subjects wearing a chest sensor that records electrodermal activity, respiration, temperature, and an electrocardiogram, with periods labelled baseline, stress, or amusement. \WESAD{} is used in two complementary ways: as a source of real physiological streams whose multi-lag temporal context the reservoir must encode (\cref{sec:ch5_physio}), and as a downstream affective-classification task (\cref{sec:ch5_wesad}).

\section{Physiological Temporal-Context Reconstruction}\label{sec:ch5_physio}
%% ------------------------------------------------------------

The benchmarks of \cref{sec:ch5_benchmarks} show that a spread of device timescales broadens memory on a random input. This section tests the same property on the multi-timescale physiological signals introduced in \cref{sec:ch5_affect}, isolating temporal-context encoding before turning to affect labels (\cref{sec:ch5_wesad}).

The reservoir is run continuously over each \WESAD{} session at $\Delta t = \SI{1}{\second}$ on four chest channels (electrodermal activity, respiration, temperature, and an electrocardiogram-derived heart rate), and a linear read-out reconstructs each channel at delays of $1$, $3$, $8$, $20$ and \SI{45}{\second}. These delays span fast phasic and beat-to-beat context, respiration- and HF-HRV-scale context, and tonic, LF-HRV-scale context~\cite{Boucsein2012EDA,TaskForce1996HRV}. Evaluation is leave-one-subject-out over all fifteen subjects, with $N=48$ nodes per bank.

Preprocessing is causal. ECG filtering and RR-interval assignment use only completed beats; resampling uses the nearest past label. Each channel is mapped to $(0,1)$ by a monotone transform fitted to the first \SI{60}{\second} only: the calibration-prefix 5th and 95th percentiles map to 0.25 and 0.75, without hard clipping later values. Thus neither later held-out values nor affect labels set the scale. The reported out-of-sample $R^2$ uses the training-subject mean as its deployable null predictor, clips reconstructed normalised physiology to $[0,1]$, and weights each held-out subject equally.

\Cref{tab:ch5_physio} reports the held-out reconstruction quality. A memoryless bank gives $R^2 = 0.636$, compared with $0.646$ for instantaneous input. A single-timescale memory raises $R^2$ to $0.679$--$0.692$, and the heterogeneous composition bank reaches $0.701$: $+0.055$ over instantaneous input and $+0.010$ over the stronger same-size homogeneous control. The heterogeneous-minus-fast difference is positive in $14/15$ subjects (Holm-adjusted $p=2.4\times10^{-4}$); heterogeneous-minus-slow is positive in $11/15$ ($p_{\mathrm{Holm}}=0.030$). The fast homogeneous bank is strongest at the shortest delays and the slow homogeneous bank at the longest; heterogeneity gives the highest overall score, but the margin is modest (\cref{fig:ch5_physio}).

\section{WESAD Affective Classification}\label{sec:ch5_wesad}
%% ------------------------------------------------------------

The downstream task is affective-state classification from the \WESAD{} physiological streams with a leave-one-subject-out linear read-out. The reservoir and the \SI{15}{\second} causal prediction smoother run on the complete physical timeline; samples with undefined affect labels are excluded only from fitting and scoring. This prevents the smoother from joining labelled blocks separated by long protocol gaps. The study that introduced \WESAD{} reports three-class chest macro-F1 $\approx0.72$ with engineered window features and conventional classifiers under leave-one-subject-out validation~\cite{Schmidt2018WESAD}; the present streaming linear read-out reaches $0.524$ averaged over bank draws (\cref{tab:ch5_sota}). The formulations differ, so this is a scale reference and not a like-for-like ranking.

\paragraph{Demonstration~A: window-level electrodermal classification.} Binary stress-versus-baseline classification from electrodermal activity, read out at the window level from the lead composition alone, reaches leave-one-subject-out macro-F1 $0.669$ (\cref{fig:ch5_wesad}a). A static baseline using the mean, standard deviation, last value, and slope of the same signal reaches $0.714$. The reservoir does not improve this \SI{60}{\second}-window task.

\paragraph{Demonstration~B: streaming three-class tracking.} The reservoir runs continuously over each session, and baseline, stress, or amusement is read out at every labelled step. \Cref{tab:ch5_wesad} decomposes the result into four matched-size banks. A majority-class predictor reaches macro-F1 $0.231$ and a stratified-random predictor $0.333$. Instantaneous input reaches $0.482$; the memoryless bank reaches $0.513\pm0.040$; and the homogeneous fading-memory bank reaches $0.545\pm0.037$. The heterogeneous bank reaches $0.524\pm0.032$, a $+0.042$ gain over instantaneous input but $-0.021\pm0.024$ relative to homogeneous, with heterogeneity higher in only one of ten matched seed pairs. At the representative seed, amusement remains the weakest class (F1 $0.35$, versus $0.82$ for baseline and $0.74$ for stress). The corrected experiment therefore supports a memory benefit relative to an instantaneous read, but not a timescale-diversity benefit for these sustained labels.

Under this protocol, fading memory helps classification; replacing the homogeneous bank with the measured heterogeneous distribution slightly lowers the seed-mean score.

\section{Continuous Monitoring Under Deployment Conditions}\label{sec:ch5_robust}
%% ------------------------------------------------------------

The sustained \WESAD{} states can often be classified from the instantaneous signal level, as shown by the static-feature baseline. Wearable measurements also contain sensor noise and motion artefacts, particularly in wrist-worn electrodermal and photoplethysmographic signals. Fading memory implements temporal low-pass filtering and may therefore reduce sensitivity to transient artefacts. The tests below add synthetic noise, measured-motion gating, and an independent sensor corpus.

\Cref{fig:ch5_robust_monitoring} tests a continuous binary stress detector (stress versus baseline plus amusement, read out at every step, leave-one-subject-out, with the same linear read-out used throughout). On clean streams, macro-F1 ranges from $0.781$ to $0.800$. At $\sigma=0.4$, instantaneous and memoryless reads fall to $0.641$ and $0.649$, while the homogeneous and heterogeneous memory banks retain $0.807$ and $0.775$. The heterogeneous-minus-instantaneous subject difference is $+0.125$ ($12/15$ positive, paired Wilcoxon $p=0.030$). Clean false-alarm rates are similar (instantaneous $0.094$, heterogeneous $0.090$ seed-mean). Transition-window F1 changes from $0.832$ to $0.848$, but the subject difference is not resolved ($6/15$ positive, $p=0.33$); all banks have zero median onset latency under the five-second stable-call definition. Temporal smoothing is useful under corruption, not for earlier detection in this protocol.

\paragraph{Accelerometer-gated motion artefact.} Because the preceding corruption is synthetic, a second test gates its amplitude with the measured chest accelerometer. At the strongest gating, the instantaneous read falls to $0.702$, the heterogeneous bank retains $0.791$, and the EMA reaches $0.810$. The heterogeneous-minus-instantaneous subject difference ($+0.087$) is not resolved ($p=0.084$), whereas EMA-minus-instantaneous is ($+0.112$, $p=0.035$; \siTempRef{app:ch5_robust}). The data-driven control therefore supports conventional temporal filtering under measured-motion corruption, but not a separate device-model advantage.

\paragraph{Classical-filter control.} A single exponential moving average reaches macro-F1 $0.804$ at $\sigma=0.4$, compared with $0.641$ for instantaneous input; its paired subject gain is $+0.171$ ($p=0.022$). A linear multi-$\tau$ EMA bank reaches $0.811$, with no resolved gain over the single EMA ($+0.006$, $p=0.20$). The heterogeneous device model reaches $0.775$ and is lower than the EMA bank by $-0.052$ ($p=0.030$; \siTempRef{tab:ch5_filter}). Robustness is therefore attributable to temporal low-pass filtering, and the linear digital control is superior on this test. The proposed material role is passive filtering, not an accuracy advantage over that control.

Cognitive and emotional stress are compared with relaxation; physical exertion is excluded. On clean streams, seed-mean heterogeneous and instantaneous scores are $0.644$ and $0.639$; the representative-seed subject difference is not resolved ($p=0.39$). At $\sigma=0.4$, they are $0.629$ and $0.451$: a $+0.177$ gain, positive in all twenty subjects ($p=1.9\times10^{-6}$; \cref{tab:ch5_crosscorpus}). This independent corpus reproduces the noise-response ordering, while confirming that the clean-stream advantage is absent.

\section{Toward a Worn Device: Sensor Site and Operating Budget}\label{sec:ch5_deploy}
%% ------------------------------------------------------------

The robustness of the previous section is a laboratory statement until two further questions are addressed: whether the advantage survives a consumer-grade sensor, and what can be said about an operating budget. The first is tested with the \WESAD{} wrist recordings. For the second, only a reference calculation is possible because the simulated \PEO{} nodes were not measured as a wired bank.

\paragraph{Sensor site.} \WESAD{} records each session with both a chest strap and an Empatica E4 wrist band. The wrist band has fewer and noisier channels: skin conductance, skin temperature, and photoplethysmography-derived heart rate, without respiration. On clean wrist data (\cref{tab:ch5_wrist}), instantaneous and heterogeneous scores are $0.724$ and $0.736$. At $\sigma=0.4$ they are $0.615$ and $0.732$; the paired subject gain is $+0.106$ ($11/15$ positive, $p=0.035$). The corresponding chest scores are $0.641$ and $0.775$. Clean wrist false-alarm rates are not improved (instantaneous $0.112$, heterogeneous $0.115$), so the supported benefit is robustness under injected corruption rather than fewer clean-stream alarms.

\paragraph{Operating-budget reference.} The parameter count is exact for the simulated architecture: the device dynamics are fixed, and the fitted $(N{+}1)\times K$ read-out contains $75$ weights for $N=24$, $K=3$, or $147$ for $N=48$. The read-out also requires $NK$ multiply--accumulates per step. Energy is less certain. Recalculation of one proof-of-concept \SY{}/\Hybrane{}/\LiTf{} junction gives \SIrange{0.084}{1.55}{\micro\joule} across its positive write sequence (median \SI{1.08}{\micro\joule}). Multiplying that median by 24 nodes gives a reference core cost of \SI{25.9}{\micro\joule} per update, or \SI{25.9}{\micro\watt} at one update per second; the corresponding 48-node value is \SI{51.8}{\micro\watt}.

These products are not power predictions for the proposed reservoir. They transfer a \SI{1}{\volt} result from one large-area \Hybrane{} junction to \PEO{} models identified at \SIrange{3}{4}{\volt}, without measured bank wiring, read energy, or peripheral circuits. They exclude the sensor analogue front-end, analogue-to-digital conversion, addressing, and control, and are neither an upper nor a lower bound. The device response remains faster than the sub-hertz physiological signals considered here, and its relaxation would perform the temporal filtering during the write/read cycle. The assumptions are tabulated in \siTempRef{app:ch5_deploy}.

\section{Matching Device and Task Timescales}\label{sec:ch5_designrules}
%% ------------------------------------------------------------

Performance depends on the overlap between device and task timescales (\cref{fig:ch5_tau_coverage}). In the single-composition sweep, the lead cell gives the highest memory capacity for the seconds-scale benchmark (\cref{fig:ch5_composition_sweep}). For the multi-lag physiological task, no single cell covers the full delay range, and the heterogeneous bank gives the highest single-bank score (\cref{tab:ch5_physio}).

\paragraph{Effect of timescale breadth.} \Cref{tab:ch5_summary} separates fading memory from timescale breadth. The bounded benchmark does not resolve a total linear-memory advantage: the heterogeneous-minus-homogeneous difference is $+0.33\pm0.60$, positive in $7/10$ seeds. It does raise nonlinear information-processing capacity and change the lag profile. On real physiology, heterogeneity gives a modest $+0.010$ context-reconstruction gain over the stronger homogeneous control, but loses $0.021$ macro-F1 on sustained three-class labels. Under corruption, the homogeneous bank is also stronger. The task, not diversity alone, determines the useful distribution.

When one slow timescale dominates, as in the sustained stress labels and stress-monitoring task, the best-matched homogeneous bank is better by about $0.01$--$0.03$ macro-F1. The available variation comes from composition and device-to-device scatter; chemistry and drive amplitude provide additional, sample-limited axes in \cref{ch:comparative}.

\section{Limitations and Scope Conditions}\label{sec:ch5_limitations}
%% ------------------------------------------------------------

\paragraph{In silico.} The demonstrations are simulations. Each node is the measured $\phi \otimes \lambda \otimes f$ behavioural model of \cref{sec:ch5_model}, not a bench reservoir. Every figure caption names the data behind it. A wired hardware reservoir remains future work.

\paragraph{The composition assumption.} As detailed in \cref{sec:ch5_model}, write nonlinearity and fading memory were measured separately, at different write amplitudes and one inter-pulse cadence. Combining them assumes that the two regimes are compatible; even the direction and magnitude of the omitted coupling are uncertain for the silver/\PEO{} system. In a sensitivity analysis, each node's retention was rescaled with its write exponent over $\kappa=-0.5$ to $+0.5$. The mean heterogeneous-to-homogeneous capacity ratio remains small, $1.04$--$1.09$ (\siTempRef{app:ch5_controls}). The gold/\TMPE{} negative-polarity measurements provide an external directional reference, $\rho=+0.46$ between write depth and decay half-time across $28$ single-run traces. The nominal cards already have a stronger across-card rank association ($\rho\approx+0.57$), so the central external estimate maps to $\kappa^{\star}=0$ and its upper confidence limit to about $+0.31$; the capacity ratio is $1.08$ at both points. Because host, electrode, polarity, and protocol differ, this is a sensitivity anchor rather than validation of the composed silver model. A matched-amplitude experiment on the lead composition that varies pulse count and inter-pulse interval together is required.

\paragraph{Operating regime and read-out.} The model is identified only in the measured sub-kilohertz regime; fast temporal tasks are outside its scope. Every read-out is a single ridge regression because a nonlinear read-out could supply the task nonlinearity independently of the reservoir. The read is assumed to be sub-threshold and state-preserving.

\paragraph{Heterogeneity axes.} The quantitative comparisons span the replicated \PEO{}/\LiTf{} composition grid; the single recovered \PEO{}~0.15 substrate is excluded. Chemistry and drive amplitude enter only as secondary controls because their matched cells contain at most two substrates (\cref{ch:comparative}); Demonstration~B is a proof of principle for composition heterogeneity, not a powered comparison across chemistries. The cards index composition, but thickness and other fabrication variables are not fully separable from that design. The available covariate checks do not explain the composition association, yet they cannot prove composition is the sole cause (\cref{fig:ch4_thickness_control}, \cref{sec:ch4_materials}).

\paragraph{Corpora, protocol, and negative controls.} The affective results use \WESAD{} as the main corpus, and noise robustness is replicated on the PhysioNet Non-EEG dataset (\cref{sec:ch5_robust}). A broader multi-corpus study remains future work. In \WESAD{}, the experimental blocks follow a fixed protocol rather than a counterbalanced order. Affect label, elapsed time, and slow session drift are therefore partly entangled: causal prefix calibration prevents future-sample leakage, but it cannot establish that a classifier is specific to affect rather than protocol position. The sustained block labels also do not provide independent ground truth for physiological onset, so the transition and latency analyses quantify agreement with protocol boundaries, not the onset of an internal state.

The strongest robustness results use synthetic, channel-wise corruption and should be read as controlled stress tests. The measured-motion gate is a more realistic but weaker control and does not resolve a heterogeneous-over-instantaneous advantage. Two further comparisons do not show a device-specific improvement: timescale heterogeneity lowers the seed-mean final-label score relative to the slow homogeneous control (\cref{sec:ch5_wesad}), and the nonlinear device encoding is inferior to a linear multi-$\tau$ EMA under strong synthetic corruption (\siTempRef{tab:ch5_filter}). The corrected random-input benchmark likewise does not resolve a total linear-memory advantage, although it does show higher nonlinear capacity and a shifted lag profile.

\section{Summary}\label{sec:ch5_conclusions}
%% ------------------------------------------------------------

Behavioural models fitted to the measurements of \cref{ch:comparative} support temporal-computing simulations with a linear read-out. Once the node update is bounded by the measured potentiation peak and pulse count, the heterogeneous bank changes total linear memory only from $4.19$ to $4.52$ ($7/10$ seeds), but increases mean information-processing capacity from $6.31$ to $10.33$, chiefly through nonlinear degree-two terms. On \WESAD{}, a lead-cell reservoir scores $0.669$ on windowed binary EDA, below a static control ($0.714$). Streaming three-class macro-F1 is $0.524\pm0.032$ for the heterogeneous bank and $0.545\pm0.037$ for homogeneous memory. Under synthetic corruption, the heterogeneous bank retains $0.775$ while instantaneous input falls to $0.641$, but a linear EMA bank reaches $0.811$ and significantly exceeds the device model.

The additional value of a timescale distribution depends on the task and metric. It is not resolved for total random-input linear memory or sustained \WESAD{} labels. It is large for nonlinear capacity and modest but subject-resolved for multi-lag physiological reconstruction ($+0.010$ $R^2$ over the slow homogeneous control). Noise robustness replicates on the independent Non-EEG corpus, but represents generic temporal filtering rather than a device-specific accuracy advantage.

The next experimental steps are a matched-amplitude pulse protocol that varies pulse count and cadence, a replicated study of chemistry and drive-amplitude heterogeneity, and a wired device bank that tests the behavioural-model predictions in hardware.
